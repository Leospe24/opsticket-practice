3. REMAINING 33 FINDINGS — WHY THEY CAN BE SAFELY IGNORED
--------------------------------------------------------------------------------
None of the remaining 33 findings are used by the running Express API (`src/server.js`).
They come from background CLI tools pre-installed in the base image or build helpers:

1. `tar` (12 CVEs: 1 CRITICAL, 8 HIGH, 3 MEDIUM) — Installed: 6.2.1
   - Where it lives: Inside `@mapbox/node-pre-gyp` (used by `bcrypt` only during
     `npm ci` at build time) and `/usr/local/lib/node_modules/npm`.
   - Why safe to ignore: The running OpsTicket API never extracts `.tar` archives.

2. `pacote`, `sigstore`, `@sigstore/core`, `postcss-selector-parser`, `picomatch`
   - Where they live: Inside `/usr/local/lib/node_modules/npm` (the global `npm`
     CLI bundled inside `node:22-alpine`).
   - Why safe to ignore: Only used when running `npm install`; never imported or
     executed by `node src/server.js`.

3. `brace-expansion` (2.0.2) & `ip-address` (10.1.0)
   - Where they live: Internal sub-dependencies of the global `npm` CLI inside
     `/usr/local/lib/node_modules/npm` (the app's own copies in `/app/node_modules`
     were already upgraded to 1.1.21 and 10.7.4).
   - Why safe to ignore: Not loaded by the application at runtime.

4. `http-cache-semantics` (CVE-2026-93748 — HIGH)
   - Status: `affected` (No Fixed Version released by maintainer yet).
   - Why safe to ignore: Only used by `npm`/`node-pre-gyp` HTTP caching during
     package installation, not by the Express API.
